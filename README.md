# HowToBeHuman

A MediaWiki instance hosted on a single OVHcloud VPS-2 (Docker Compose + Caddy with automatic HTTPS).

## Architecture

```
                    ┌──────────────┐
Internet ── :80/443 │    Caddy     │  automatic Let's Encrypt
                    └──────┬───────┘
                           ▼ :80
                    ┌──────────────┐     ┌──────────────┐
                    │     wiki     │────▶│      db      │
                    │ MediaWiki    │     │ MariaDB 11.4 │
                    │ 1.46.2       │     │              │
                    └──────────────┘     └──────────────┘
```

VPS-2 2027 specs: 4 vCores / 8 GB RAM / 75 GB NVMe, ~$8.50/mo, unlimited traffic,
daily backup included.

## Project Structure

```
.
├── docker-compose.prod.yml   # Prod stack: wiki + db + caddy (prebuilt images)
├── vps/
│   ├── README.md             # Ordering, DNS, provision, first-deploy runbook
│   ├── Caddyfile             # Reverse proxy ({$DOMAIN} -> wiki:80)
│   ├── provision.sh          # One-time VPS setup (Docker, UFW, fail2ban)
│   └── deploy.sh             # Deploy/refresh (git pull + compose up + health check)
├── wiki/
│   ├── extensions-custom/    # Your custom extensions (extension.json per dir)
│   ├── skins-custom/         # Your custom skins (skin.json per dir)
│   └── LocalSettings.php     # Generated by the installer, gitignored, lives here
├── .github/
│   └── workflows/
│       └── deploy-vps.yml    # Auto-deploy to VPS on push to main (SSH)
├── .githooks/                # Pre-commit/pre-push validation (compose + shell)
├── Makefile                  # Command shortcuts (make help)
└── .env.example              # DOMAIN, VPS_*, MW_* template
```

## Quickstart

Local prod stack (needs `DOMAIN` + `MW_DB_PASSWORD` in `.env`):

```bash
cp .env.example .env   # set DOMAIN, MW_DB_PASSWORD
make prod-up           # -> http://localhost:80 (via Caddy on :80/:443)
```

Full VPS runbook (order → DNS → provision → installer): [`vps/README.md`](vps/README.md).

## Extensions

All future functionality ships as MediaWiki extensions:

* Bundled: enable in `wiki/LocalSettings.php` (e.g. `wfLoadExtension( 'Cite' );`),
  then `make wiki-update`.
* Custom (yours): develop under `wiki/extensions-custom/MyExtension/` (see its
  `README.md`), load by path in `LocalSettings.php`, no rebuild needed. Same
  pattern for skins in `wiki/skins-custom/`.

## Environment Variables

| Variable | Description | Required |
|---|---|---|
| `DOMAIN` | Public domain (Caddy requests TLS for it) | Yes |
| `MW_DB_NAME` / `MW_DB_USER` | MariaDB database / user (default `mediawiki`) | No |
| `MW_DB_PASSWORD` | MariaDB password (also entered in the installer) | Yes |
| `MW_SITE_NAME` | Wiki site name | No |
| `VPS_HOST` / `VPS_USER` / `APP_DIR` | SSH deploy target (`make vps-*`) | Deploy only |

## Backups

VPS daily backups are included. Additionally back up the database
(`mariadb-dump` from the `db` service — see `vps/README.md`) and the
`wiki_html` volume (uploads + `LocalSettings.php`).
